APREIS CGS TUNI — WEBSITE STARTER
=================================
This folder contains a ready-to-upload starter website:
index.html, activities.html, photos.html, batch.html, about.html, style.css

PUBLISH ON NETLIFY
1. Extract this ZIP so the APREIS_CGS_TUNI folder and its HTML files are visible.
2. Open https://app.netlify.com/drop and sign in/create an account.
3. Upload/drag the extracted folder that contains index.html. If the page requests a ZIP,
   create a ZIP of the CONTENTS so index.html is at the top level.
4. Wait for the site to publish. Copy the URL ending in netlify.app and test it on your phone.
5. Keep your current Google Sites page until this new site has been checked.

EDITING
- Activities page: replace VIDEO_ID_1 and VIDEO_ID_2 with your YouTube video IDs.
  For a link like https://www.youtube.com/watch?v=AbCd12345XY, the ID is AbCd12345XY.
- Photos page currently contains illustrated placeholders, not real school photos.
  Replace them only after you have approved photos and are ready to edit the page.
- Update text and timetable only with confirmed information.
- Do not publish student phone numbers, addresses, marks or sensitive personal details.
- Netlify free plan has usage limits and terms can change. A custom domain is generally
  purchased separately. A custom domain does not guarantee immediate Google indexing.
